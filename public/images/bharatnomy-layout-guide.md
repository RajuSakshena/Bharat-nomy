# Bharatnomy — Layout & Text Placement Guide
### For the web designer — pairs with `bharatnomy-website-copy.md`

How to use this document: each section below names a page element, tells you which text from the copy doc goes there, how it should be aligned, and any placement notes. Copy is final as written — please don't paraphrase or shorten it further without checking back. Where I've left a design decision open, I've said so explicitly.

**Global conventions (apply site-wide unless a page says otherwise)**

| Element | Alignment | Notes |
|---|---|---|
| Page body copy | Left-aligned | Never center long paragraphs — hurts readability |
| Headlines (H1) | Left-aligned by default | Centered only on the landing page hero (see below) |
| Section labels (e.g. "RESEARCH", small caps eyebrow text) | Left-aligned | Sits above each H2, same left edge |
| Buttons / CTAs | Left-aligned within their section | Exception: landing page closing CTA band, which should be centered |
| Max text line width | ~65–75 characters per line | Standard readability constraint for body copy — constrain the text column even on wide screens |
| Team bios, list items | Left-aligned | Use consistent left rule/indent if presented as a list |

## 1. Landing Page

| Order | Element | Content source | Alignment | Notes |
|---|---|---|---|---|
| 1 | Logo / wordmark "Bharatnomy" | — | Top-left (standard nav position) | |
| 2 | Hero headline | "Bharatnomy" + tagline (pick one from copy doc) | **Centered**, full-width hero band | This is the one place on the site that should feel like a title page, not a document |
| 3 | Hero subtext | "India's economy doesn't run in silos..." paragraph | Centered, but constrain width to ~600px so it doesn't stretch edge to edge | |
| 4 | "What we do" paragraph | 3-line paragraph from copy doc | Left-aligned, constrained width (~600–700px), can be centered as a block on the page but text itself stays left-aligned | |
| 5 | Focus areas grid | 5 tiles (Climate, Energy, Macro, Equity, Commodity) | Grid layout, each tile left-aligned internally | 5 items — suggest a 3+2 or 5-across grid depending on screen width; each tile is a short label + one line, so keep tiles compact, not full cards |
| 6 | "Why now" editorial paragraph | The independence/non-partisanship paragraph | Left-aligned, single column, narrower than full width (~600–700px) — this is the most important paragraph on the page editorially, give it breathing room (extra margin above/below) | |
| 7 | Closing CTA band | Headline + subhead + email field + Subscribe button | **Centered**, full-width band, visually distinct background (different shade/color block) to mark it as the page's final action | |

**Overall page rhythm:** hero (centered) → everything else (left-aligned, single readable column) → CTA band (centered). This centered-left-centered pattern is intentional — it makes the hero and closing CTA feel like bookends.

## 2. About Page

| Order | Element | Content source | Alignment | Notes |
|---|---|---|---|---|
| 1 | Page header | "About" (or omit if design doesn't use page titles) | Left-aligned | |
| 2 | Opening / mission paragraphs (2 paragraphs) | "Bharatnomy is an independent research firm..." | Left-aligned, constrained width | |

**Note for designer:** team bios don't yet have photos or last names. Leave a clearly bounded placeholder (image frame + name line) so these can be dropped in later without a layout change.

## Site-wide elements not covered above

- **Navigation:** suggest order — Research / Datasets / Dashboards / About / (Careers, if included in nav vs. footer-only). Landing page is the logo/home link, not a nav item.
- **Footer:** general inquiries email, media/press contact, and (once decided) social links. Keep footer left-aligned or in evenly spaced columns — avoid centering footer text blocks.
- **Newsletter field:** appears on Landing, Research, Datasets, and Dashboards pages per the copy doc — keep this component visually identical across all four so it reads as one consistent action, not four different widgets.
