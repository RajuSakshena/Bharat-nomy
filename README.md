# BharatkiEconomy

Evidence-based public policy and economic research platform for India.

![Astro](https://img.shields.io/badge/Astro-5.0-orange?style=flat-square&logo=astro)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4.0-38B2AC?style=flat-square&logo=tailwind-css)

## Prerequisites
- Node.js 20+

## Quick Start
```bash
git clone <repository-url>
cd Bharatnomy
npm install
npm run dev
```

## Local CMS Development
To use the local CMS setup with Decap CMS, run the proxy server in a separate terminal:
```bash
npx decap-server
```
Then visit `http://localhost:4321/admin` to edit content.

## Deployment
Deploy to Netlify or Vercel:
```bash
npm run build
```

## Editorial Guidelines
- Start research with a 3-4 sentence plain-language summary.
- Avoid clickbait and sensationalism.
- Provide primary source citations.
